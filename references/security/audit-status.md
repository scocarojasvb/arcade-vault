# Estado de seguridad por chequeo

Memoria del subagente `security-auditor` (`.claude/agents/security-auditor.md`). Un chequeo marcado
`aceptado` es un desvío consciente documentado en un spec — **no se re-reporta como hallazgo** salvo
que el contexto haya cambiado. `ok` significa verificado con evidencia real en esa corrida; `sin
verificar` significa que la herramienta no estuvo disponible — nunca se marca `ok` sin evidencia.
